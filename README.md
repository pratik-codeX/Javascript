# Javascript
# JavaScript Learning Journey

A structured repository for learning JavaScript through the official [MDN JavaScript documentation](https://developer.mozilla.org/en-US/docs/Web/JavaScript).

This repository contains my notes, examples, exercises, experiments, and projects.

## Goals

* Understand JavaScript fundamentals and core features
* Write JavaScript independently
* Learn how JavaScript is executed
* Practice functions, arrays, objects, classes, and modules
* Understand asynchronous JavaScript and promises
* Work with the DOM, events, storage, and web APIs
* Build practical projects

## Learning Process

```text
Read MDN → Write Notes → Practice Code → Test Concepts → Build Projects
```

Each topic should include:

* A short explanation in my own words
* Relevant MDN links
* Code examples
* Exercises
* Common mistakes or observations

## Main Topics

* Grammar and types
* Control flow and error handling
* Loops and iteration
* Functions
* Expressions and operators
* Numbers and strings
* Arrays and collections
* Objects and classes
* Prototypes and inheritance
* Promises and asynchronous JavaScript
* Modules
* DOM and events
* Web storage
* Fetch and web APIs
